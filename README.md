## Présentation

Nametags enchantés pour renommer un item en couleur (remplace ItemTags, compatible avec ses tags)

Utilisé sur : **Opale**.

## Dépendances

- Obligatoires : `NBTAPI`

## Commandes

| Commande | Alias | Description | Permission |
|---|---|---|---|
| `/shitemtags` | — | Donne des Nametags enchantés. | — |

## Permissions

| Permission | Description | Par défaut |
|---|---|---|
| `itemtags.command.give` | /itemtags give, giveall et reload | `op` |

## Configuration

Fichiers par défaut repris du serveur (secrets remplacés par `CHANGE_ME`) :

- `config.yml`

## Compilation

Java 21 et Maven :

```bash
mvn clean package
```

Le jar est généré dans `target/`.
